# Om Khairate - In Motion

Interactive engineering portfolio built with Three.js, Vite and Lucide.

Live website: https://omkhairate.github.io/

## Development

Use Node.js 22 or later.

```sh
npm ci
npm run dev
```

## Publishing

Push to `main`. GitHub Actions builds `dist/` and deploys it to GitHub Pages.
The root domain uses Vite's default `/` base path.
